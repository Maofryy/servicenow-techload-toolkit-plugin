# PRODUCT.md

## Product Purpose
ServiceNow TechLead Toolkit — a Claude Code plugin that gives ServiceNow tech leads,
architects, and platform owners an AI-powered delivery pipeline: from requirements
challenge through platform blueprinting, estimation, code review, and stakeholder
communication.

## Users
Primary: ServiceNow tech leads and solution architects
Secondary: Platform owners, delivery managers, and consultants working on
ServiceNow implementations

## Register
brand — the HTML templates and visual outputs are the deliverable that users see.
Design quality directly reflects on the toolkit's credibility.

## Tone
Authoritative, precise, consultative. Never casual. Data-forward over decorative.

## Anti-references
- Generic SaaS dashboards with gradient cards
- Overly animated "agency portfolio" aesthetics
- Dark cinematic themes for client-facing output (reserve for technical deep-dives)
